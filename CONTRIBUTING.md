# Contributing to TinyPM V4

ATiny is built for **Windows users moving to Linux**.

Rules:
- Beginner-friendly output by default
- Power-user output behind `-p`
- Cross-distro compatible (including apt/dnf/pacman/zypper/apk)
- Flatpak and Snap should be optional
- Run `./scripts/build.sh` and `./scripts/e2e-smoke.sh` before submitting changes

Please keep changes readable and predictable.
